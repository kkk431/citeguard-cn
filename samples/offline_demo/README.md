# 离线演示包（samples/offline_demo）

给答辩现场断网、内网或不想上传真实论文时使用，**完全不需要外网**。

- `paper.txt`：一篇演示用的中文短文 + 11 条参考文献。前 10 条是真实公开文献的题录（取自一篇开放获取论文的参考文献，仅保留元数据）；第 11 条是**故意虚构**的演示条目，用来展示「未核实」状态，不参与任何评测。
- `library.ris`：前 10 条题录组成的本地题录库，可直接导入「题录库」页面。
- `meta.json`：来源与虚构条目说明。

## 怎么用

1. 启动离线模式服务：

   ```bash
   # Windows PowerShell
   $env:CITEGUARD_OFFLINE=1
   python -m uvicorn web.app:app --host 127.0.0.1 --port 8010
   ```

2. 打开 `/library`，导入 `library.ris`（格式选「自动识别」即可）。
3. 打开首页，把 `paper.txt` 拖进去（或直接上传 `.txt`），在「本地题录库」里选中刚导入的库，开始分析。
4. 预期结果：**10 条「精确匹配」、1 条「未核实」**；支持度列显示「离线未判定」；GB/T 字段规则检查照常工作。页面顶部有离线横幅。

## 为什么是 10 + 1

离线演示要能同时说明两件事：系统确实能做字段级核验（10 条命中本地库），也不会把「库里没有」硬说成「假文献」（第 11 条显示未核实，而不是严重不符）。演示时建议主动讲这一点，比只展示全绿更有说服力。

`scripts/build_offline_demo.py` 可重新生成这个包（需要 `data/real_corpus/hanspub_152575.pdf`，该文件不入库）。
