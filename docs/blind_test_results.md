## 2. 4 条 Major 人工复核：是解析噪声，不是“论文不存在”

不是重跑或调参，只是逐条看原始字符串：

- Llama 2 第 1 条：`title` 变成了 “Scaling instruction-finetuned language models. Christopher Clark, …”，
  `raw` 是两条文献被粘在一起（Adam Roberts… 与 Christopher Clark…）。
- Llama 2 第 2 条：`title` 是一整串作者（Reiichiro Nakano, Jacob Hilton, …），没有题名。
- DeepSeek-V3 两条：`title` 以 `URL .` 或 `3476145. URL` 开头，是两栏 PDF 的
  URL/页码碎片与下一条作者被拼在一起。

**结论：这 4 条不是“核验器把真论文判成假的”，而是“引用切分失败后把作者/URL 当成了题名”。**
但产品最终仍展示为 **Major**，对用户就是一次严重误判，所以：

> “零严重误判”当前只对参考文献切分干净的 PDF 成立，**不能作为对所有真实论文的普适承诺**。

## 3. 根因

1. **ACM/两栏排版 + 行内换行**：参考文献每条以年份结尾、条目之间没有空行；
   现有切分器假设“作者在前、年份在前部”，于是 Llama 2 的 100+ 条只被切成 9 条。
2. **两栏阅读顺序**：DeepSeek-V3 的 URL 与下一条作者跨栏粘连，条目以 `URL .` 开头，
   切分器只识别出 2 条。
3. 这两类错误会直接把“作者列表/URL 碎片”送进核验，进而产生 Major。

## 4. 对既有数字的影响

- 22 篇真实论文（409 条）与 BERT/Mamba/FlashAttention 的 **0 Major** 结果仍然有效，
  但这些 PDF 的参考文献版式更容易切分，存在**选择偏差**，不能外推。
- 课程/比赛材料里如引用“0 严重误判”，必须同时写清适用范围：
  “在 409 条已发表中文文献 + 3 篇经典英文论文上 0 Major”，并注明本轮盲测暴露了版式局限。

## 5. 下一步（按顺序）

2. 增加“年份结尾”条目切分与 `URL .` 噪声清理，并把这三篇 PDF 加进回归夹具；

4. 在修复前，不再对外宣称普适的“零误判”。
