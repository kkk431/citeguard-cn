# 批量聚合（机构 / 课程视图）

单篇报告回答「这篇论文怎么样」；批量聚合回答「这一批论文整体怎么样、问题集中在哪、先看哪篇」。

## 入口

1. 打开「历史报告」，勾选若干份**已完成**的任务（复用「打包」勾选框，最多 50 份）。
2. 点「聚合健康画像」→ `/aggregate?ids=...`。
3. 页面显示：平均健康分、等级分布、五维平均、最常见问题 Top 5、逐篇排序；「导出 CSV」下载明细。

接口：

- `GET /api/aggregate?ids=a,b,c` → `{summary, grades, dimensions, top_issues, papers, missing, duplicates, note}`
- `GET /api/aggregate.csv?ids=a,b,c` → UTF-8 BOM CSV（Excel 直接打开）

**去重规则**：同一文件名只保留第一份报告（避免同一篇论文重复分析把平均值拉偏），被合并的 job id 记在 `duplicates`；没有完成报告的任务记在 `missing`，都不计入统计。

### Major 9 条怎么解释（必须说清）

逐条人工查看后：8 条来自 `W2996762219.pdf`、1 条来自 `hanspub_152702.pdf`，**都不是「真论文被说成假」**，而是解析噪声：

- `W2996762219.pdf` 的参考文献是密集双栏，解析时把相邻两条粘成一条，DOI 被截断成 `10.1159/e000486793` 这类不存在的串；`verify` 按 DOI 查不到，标了 Major。
- `152702.pdf` 同类：DOI 跨行断开。

因此：**聚合页的 Major 计数是「报告里被标为 Major 的条目数」，不是独立核验后的真实伪造数**。这批数据不能用来宣称「9 条造假」，也不能用来重算 409 条语料的 0 Major。它的价值是暴露解析薄弱点（双栏/断行 DOI），已记录为后续修复项。

## CSV 列

`job_id, 论文, 健康分, 等级, 置信权重, 参考文献, 真实一致, 元数据偏差, 未核验, 无法核验, 疑似错配, 格式问题, 证据矛盾, 部分支持, 缺少证据, 正文未引用, 引注编号缺失, 撤稿`

## 边界

- 只统计**已存报告**；同一文件重复分析默认合并（保留第一份）。
- 健康分是规则加权分（见 `docs/health.md`），不是期刊/评审标准；未检测维度不计入平均。
- 五维平均只对有该维度分数的论文取平均，因此每维的「篇数」可能不同。
- 支持度一栏在没配置判定模型或没有摘要时会显示「本次未检测」，不是 0 分。
- 聚合不改变单篇报告；有问题仍回到单篇的条目抽屉处理。
