# 正文引注抽取：真实语料自动评测

这是**自动检查**，不是人工准确率标注。它回答三个问题：论文里能不能找到引注、找到的引注有没有指向真实条目、引注键是否真的出现在被抽出的句子里。

## 语料

`data/real_corpus/` 下 22 篇开放获取 PDF（20 篇中文期刊 + 2 篇英文），解析路径与产品一致：`extract_text_with_meta` → `split_references` → `parse_reference_list` → `extract_citations`。没有针对这 22 篇做任何特判。

## 结果（2026-11-11，1.0.7）

| 指标 | 数值 | 口径 |
| --- | --- | --- |
| 有引注的论文 | **21 / 22（95.5%）** | 正文至少抽到 1 处引注 |
| 抽到引注总数 | **543** | 数字键、`文献[n]`、作者年、中文作者年 |
| 参考文献被引条目 | **318 / 529（60.1%）** | 数字编号 + 作者年解析（1.0.7 新增作者年解析） |
| 键自洽率 | **486 / 543（89.5%）** | 抽出的 key 必须原样出现在同句里；只是必要条件，不是语义准确率 |

分风格看：数字编号类论文大多 0.9–1.0；3 篇中文作者年论文因姓名/年份写法不统一，覆盖率明显偏低；`W2098348787.pdf` 用的是**不带括号**的 `Parr 2007` 写法，当前抽取器不支持，所以是 0——这是真实边界，不是论文没引用。

## 边界（不要外推）

- **不是人工抽检准确率**：没有 50 条人工标注，89.5% 只是“键在句子里”的自洽率。
- 没有页码：正文抽取不带页界，报告里的引注暂时不能定位到页；页码映射是单独工作项。
- 语料不是随机抽样：20 篇来自同一开放期刊，2 篇来自 OpenAlex；不能外推到“所有中文论文”。
- 不支持无括号作者年、上标数字、图注里的引用；跨栏引用未单独处理。
- 60.1% 是**下界**：作者年匹配只做姓氏+年份，遇到同名/多作者会漏。

## 复现

```bash
PYTHONPATH=src python scripts/eval_citation_anchor.py
```

输出 `data/experiments/citation_anchor_real.json`（逐篇）与 `citation_anchor_sample.csv`（40 条随机抽样，供人工看）。

## 页码定位（1.0.8）

报告里的每条引注会带 `page`：用 pdfplumber 逐页取文本、归一化空白后，把引注句子按子串匹配到页。10 页真实论文 18 处引注中 **17 处命中（94.4%）**；跨页断开的句子会漏，属于已知限制，不声称 100%。


## 图表引用（1.0.10）

正文里“如图 3 所示 / 见表 2 / Fig. 3 / Table 2”这类对图表的提及，也作为引注上下文抽取（规则匹配，只记录“提到了哪张图/表”，不判断图表内容对错）。

- 语料：`data/real_corpus` 22 篇，12 篇检出图表提及，共 **185 处**、去重到 **101 个**“图/表”标签。
- 单篇示例（hanspub_152575）：15 处提及、10 个标签；报告页引注面板显示“正文还提到 15 处图表（图 1、Figure 1、图 2…）”。
- 口径与边界：`data/experiments/citation_captions.json`；只做规则匹配，数字是下界；双语句子里的“图 1 / Figure 1”会分别计入；`图 3.3` 这种小节号、`发表 1~2 篇` 这种词内“表 1”已排除。
