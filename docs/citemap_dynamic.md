# CiteMap 动态生成

CiteMap 不再只展示两个固定主题。输入一个研究主题（或一组 DOI），系统会从
OpenAlex 检索有摘要、有 DOI 的论文，生成一张“主题 × 论文 × 机器断言/证据”的地图。

这是**机器层**，不是人工标注：

- 每篇论文生成 1 条机器断言（摘要中的结果句）和 1 条机器证据（同一句，逐字来自摘要）；
- 界面标“机器候选 · 仅摘要 · 未人审”，不进入人工示例统计；
- 只表示论文报告过该句，不代表支持任何跨论文主断言；
- 至少 5 篇有摘要的论文才生成，避免空图。

## 使用

1. 打开 `/citemap`；
2. 在顶部输入主题，如“生成式 AI 与教育公平”，点击“检索并生成”；
3. 或展开“用自己的论文（DOI）”，每行一个 DOI（最多 20 个），至少 5 个可解析；
4. 生成后自动跳转到新主题，可继续搜索、查看论文摘要、复制断言。

## 数据与 API

```text
POST /api/citemap/generate
{
  "topic": "生成式 AI 与教育公平",
  "question": "可选，主题问题",
  "query": "可选，检索词；缺省用 topic",
  "limit": 15,
  "dois": ["10.xxxx/..." ]
}
```

返回 `{ok, topic_id, papers, claims, evidence, machine}`。生成的数据写入
`data/evidence_map/dynamic/<topic_id>/`，并注册到 `data/evidence_map/index.json`；
入口页面仍读取同一套 corpus/extraction schema。

## 固定示例的机器层

固定示例的 30 篇论文也已补齐机器卡片（每篇至少 1 条），但人工示例 8 条与
105 格人工核对结果保持不变。详见 [证据地图](evidence_map.md#静态地图的机器层2026-11-15)。

## 边界

- 检索只覆盖 OpenAlex 有摘要、有 DOI 的论文，中文文献召回有限；
- 机器断言是单篇论文摘要句，不是跨论文综合，也没有人工语义核对；
- 主题名会变成 `dyn_<hash>`，不修改固定示例；
- 生成失败会返回 400/502，原因写在响应 `detail`，不会写入半张图。
