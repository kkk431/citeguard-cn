# 中文文献元数据：公开源现状与我们的处理方式

结论先说：**不存在可以免费按题名检索中文期刊元数据、且允许程序调用的公开 API**；
“中文引文核验”方向的公开数据集也基本空白。这不是我们没找，是生态现状。下面是核实记录。

## 一、实测：问题不在匹配，在收录

以真实语料 `data/real_corpus` 的 22 篇论文、409 条参考文献为例（`data/experiments/verify_real.json`）：

- 210 条中文引文里，**只有 1 条带 DOI**（`10.15886/j.cnki.hnus.202410.0119`）；
- 对 12 条 Unverified 中文题名做 OpenAlex `title.search` 抽样：**命中数全部为 0**；
  做全半角/书名号归一化后仍是 0 —— 说明这些中文社科期刊根本没有进入 OpenAlex；
- Crossref 对同一批题名同样不返回可用的中文记录。

所以中文覆盖率 12.4% 的根因是**索引不收录**，不是标题归一化能救的。

## 二、公开中文源与接口状态（2026-10 核实）

| 源 | 内容 | 程序接口 | 能否用于本项目 |
|---|---|---|---|
| [CSTR](https://www.cstr.cn/)（中科院） | 科技资源标识 | 有 API，但用于**标识注册/详情**，需授权，不是题名检索库 | 否 |
| [ChinaXiv](http://eprint.las.ac.cn/)（中科院预印本） | 预印本 | 开放获取，但以整库/OAI 为主，无按题名检索 API | 仅预印本场景 |
| [国家哲学社会科学文献中心](http://www.ncpssd.org/) | 人文社科全文 | 免费网页检索，**无公开 API** | 人工核对 |
| [PubScholar](https://pubscholar.cn/)（中科院公益学术平台） | 综合学术资源 | 免费网页检索，**无公开 API** | 人工核对 |
| CNKI / 万方 / 维普 / 超星 | 中文期刊全文 | 商业库，机构订阅；无免费开放 API | 人工核对 |
| OpenAlex / Crossref | 国际开放索引 | 有 API | 中文社科覆盖≈0（实测） |
| China DOI（handle） | DOI 解析 | 已接入 | 仅当引文带 DOI（本语料 1/210） |

参考：[CSTR 接口文档](https://www.cstr.cn/v3_article_data.pdf)、
[DOAPR: ChinaXiv](https://doapr.coar-repositories.org/repositories/chinaxiv/)。

## 三、我们实际怎么解决

1. **本地题录库**：支持 RIS / EndNote / BibTeX / CSL-JSON / GB/T 文本导入，
   后续核验先查本地库；已入库的文献可 100% 确定（见 `docs/real_data_eval.md` 本地库一节）。
2. **报告页一键补录**：中文引文显示 Unverified 时，卡片里给出知网/万方/百度学术/超星发现
   人工核对入口，并新增「加入题录库」按钮——人工核对一条、存一条，之后同类引文自动命中。
   这是替代“付费中文 API”的合规路径，不爬站、不破验证码。
3. **中国 DOI 平台**：引文带 DOI 时直接解析落地页核对题名/作者/卷期页。
4. **自建并开放评测集**：CiteBench-CN、ClaimSupport-CN 以 CC-BY-4.0 发布，
   填补“中文引文核验无公开数据集”的空白。

## 四、边界

- 不承诺“自动核验所有中文文献”；能做到的是：有 DOI 的自动核、有本地库的自动核、
  其余给出可点的核对入口，并把结果明确标成 Unverified 而不是猜一个状态。
- 如果后续拿到机构订阅（CNKI/万方 API），`local_library` 的导入与匹配层可以直接复用，
  不需要改核验主流程。
