# CiteMap 核对判定标准（单人主标 + 20% 双盲复核）

本文件用于 105 格「断言 × 论文」证据核对。目标不是判断论文好坏，而是判断：
**给定论文中的这段证据，是否支持/反驳该断言。**

## 三种判定

### `support` 完整支持
同时满足：
1. 证据直接陈述断言的核心关系（不是只出现关键词）；
2. 断言的限定条件（对象、场景、方向、比较对象）在证据中成立；
3. 数字/比较关系一致，或方向一致且没有明显反例。

例：断言「深度学习模型在该任务上的准确率高于放射科医生」；证据明确写“DL 显著超过放射科医生评估”。

### `partial` 部分支持
满足以下任一：
1. 只支持断言的**一个组成部分**（如只支持“高于传统模型”，未提“高于医生”）；
2. 方向一致但强度更弱（“接近/不劣于” vs “高于”）；
3. 研究对象/场景不完全一致，但属于同一问题域；
4. 只支持相关性，不支持断言中的因果/普遍化措辞。

### `no_evidence` 无证据
1. 论文没有研究该断言的对象/关系；
2. 证据与断言无关，或只出现词面重合；
3. 证据与断言方向相反（在“是否支持”问题下，相反=无支持证据，另记 note）；
4. 只有论文自述结论、没有可核对的数据/引文（若断言正是该结论，按 support/partial 判，但 note 写“仅摘要自述”）。

## 判定顺序（防止凭感觉）

1. 先读断言，圈出**核心关系**（谁和谁、什么方向、什么条件）。
2. 再读证据，找**同一关系**是否出现；只出现关键词不算。
3. 检查限定条件：对象、任务、数据集、比较对象是否一致。
4. 检查强度：相同/更强 → support；更弱/不完整 → partial。
5. 完全没研究 → no_evidence。
6. 拿不准时选更保守的一档，并在 note 写原因；不要猜。

## 置信度

`confidence_1_5`：1=猜的，3=有依据但存疑，5=非常确定。只用于分析，不参与判定。

## 双盲复核

- `main_105.csv`：主标注人独立完成全部 105 格。
- `qc_21.csv`：第二人独立完成 21 格（20%），**不要看主标注人的答案**。
- 两表填完运行 `scripts/score_citemap_single_qc.py`，只在这 21 格上报告一致率/Cohen κ。
- 对外只能写「单人主标 + 20% 双盲复核」；不能写「三人金标」或「全量双人」。

## 边界

- 机器证据只是参考，不是答案；可以看，但必须自己判断。
- 摘要级证据与全文证据要区分：只有摘要时，不能因为“看起来相关”给 support。
- 证据与断言相反时，判 no_evidence 并在 note 写“方向相反”，不要自行改断言。
