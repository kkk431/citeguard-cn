# AI 工具使用说明

本文件按竞赛「AI 工具使用说明」要求，如实说明 CiteGuard-CN 在**开发过程**和**运行时**分别使用了哪些 AI 工具、用在哪里、边界是什么。原则是：AI 只做辅助，结论必须可核验；不把模型输出冒充人工结论。

## 1. 开发过程中使用的 AI

| 用途 | 工具/方式 | 说明 |
|---|---|---|
| 代码、测试、文档初稿 | DeepSeek Harness 中的 AI 编程助手 | 生成或修改部分代码、测试、文档与实验脚本；所有改动进入版本库前经过本地测试、`verify_artifacts`、可访问性检查和 CI |
| 实验数据分析 | 同一 AI 助手 | 读取实验 JSON、汇总指标、生成图表脚本；数字以仓库内 JSON 和脚本输出为准 |
| 文案与答辩材料 | 同一 AI 助手 | 技术报告、README、截图说明的初稿；事实性数字回查 `data/experiments/` 与 `docs/evidence_matrix.md` |

边界：

- AI 生成内容不作为“用户反馈”“人工标注”或“人工核对”的证据；相关字段在数据卡、实验文档和 UI 中明确标注。
- 项目使用的第三方代码、数据、模型均登记在 `THIRD_PARTY_NOTICES.md`、`docs/licenses.md` 和 `docs/sbom.json`；AI 没有引入未登记的外部素材。
- 所有对外数字都附样本量、数据和复现命令，见 `docs/evidence_matrix.md`。

## 2. 运行时使用的 AI 模型

| 能力 | 默认/可选模型 | 模型许可 | 是否随仓库分发 |
|---|---|---|---|
| 引用支持度判定（主判官） | 托管 `deepseek-chat`（需配置 API Key）；可切本地 Qwen3-14B | DeepSeek 服务条款；Qwen3-14B Apache-2.0 | 否（权重不随仓库分发） |
| 覆盖审计（第二段） | 同一判官模型 | 同上 | 否 |
| 支持度小模型（可选） | Qwen3-1.7B LoRA、Qwen3-4B LoRA | Apache-2.0 | adapter 在 HuggingFace 发布，不随源码包分发 |
| 图表结论核验（可选） | Qwen3-VL-8B；可切 Qwen2.5-VL-7B/3B | Apache-2.0 | 否 |
| 中文查询翻译（Live） | 当前判官模型（`translate_query`），失败自动跳过 | 同上 | 否 |
| 向量召回（可选） | BGE-M3 | MIT | 否 |
| OCR（可选） | RapidOCR；PaddleOCR 仅对照评测 | Apache-2.0 / Apache-2.0 | 模型由依赖按需下载，不随包分发 |

说明：

- 模型通过 OpenAI 兼容接口调用，端点、模型名和 API Key 全部由环境变量配置；不配置模型时，支持度判定降级为“未检测”，不会伪造结果。
- `CITEGUARD_OFFLINE=1` 时，服务不调用外部模型与外部元数据源，只使用本地题录库和规则；UI 显示离线标记。
- 判官输出被约束为结构化 JSON（label/置信度/理由/证据句），证据句必须能在给定摘要中逐字找到，否则降低置信度并标注“未接地”。
- 图表核验只判断“结论与图中信息是否一致”，不做数据造假检测，也不替代人读图。

## 3. 数据与隐私

- 上传的 PDF/文本仅存本机 `data/`，任务完成后上传原件会被清理；报告、批注和导出文件留在本机。
- 只有被判定所需的引用句/摘要片段会发送到已配置的模型端点；不发送整篇 PDF。
- 不使用用户上传内容训练模型；不把用户数据写入公开数据集。
- 仓库不包含 API Key、`.env`、内网地址或未授权论文 PDF；打包脚本会做一次排除与扫描。

## 4. 标注与评测中的 AI

- ClaimSupport-CN 与 CiteBench-CN 的标签由**构造规则**生成，不是人工语义标注；`docs/data.md`、`DATASET_CARD.md` 与各实验文档均标注这一点。
- 100 条三人盲标与 CiteMap 60 格核对是**待真人完成**的独立验证，当前不宣称已完成；相关 CSV 与评分脚本已准备好。
- 外部基线（SciFact、ChartCheck、RefChecker、T2Retrieval、BGE-M3）只使用公开数据/公开结果，未针对测试集训练；对比口径见 `docs/baselines.md`。

## 5. AI 可能出错的地方

- 支持度判定会受摘要缺失、领域术语、跨语言影响；报告给出四档 + 置信度 + 证据句，低置信度会标注“建议人工复核”。
- Live 的溯源强于判定：冻结 held-out 的 hit@3 为 1.00，但 30 句中只有部分有可引用摘要，判定不能当实时真值。
- 图表核验在外部 ChartCheck 零样本上的 macro-F1 约 0.76–0.79，适合筛查，不适合替代人工定稿。
- 撤稿/勘误检测依赖 OpenAlex/Crossref 的更新，存在延迟；命中时提示用户回原文核对。

## 6. 许可与披露

- 本项目代码 Apache-2.0；模型权重不随仓库分发，使用时遵循各自模型许可。
- 第三方组件、数据和模型清单见 `THIRD_PARTY_NOTICES.md`、`docs/licenses.md`、`docs/sbom.json`。
- 如对 AI 使用有疑问，请在仓库 Issue 中提出。
