## 1. 不做（资源型/低收益项）

- 不训练/更换基础大模型，不买知网/万方/商业引文库，不承诺出版商全支持。
- 不做移动端、不做全领域 CiteMap、不做全网 Live、不做多语言。
- 不改 PPT/视频/比赛提交材料，不为了“指标好看”继续堆构造集。
- 不修改已有测试来“通过”；不把热缓存/构造集/机器候选包装成真实效果。

## 2. 执行原则

1. **先读再改**：读 `README.md`、`docs/optimization_master_prompt.md`、`docs/plan_national.md`、`docs/evidence_index.md`、`CHANGELOG.md`、当前测试与页面；先跑基线，确认 worktree 状态。
2. **一个改动一个验证**：每项都要有测试/页面截图/命令结果；没有验证不算完成。
3. **证据留档**：所有数据、测试结果、截图必须保存（见 §5），并在 `docs/evidence_index.md` 登记。
4. **不破坏现有链路**：报告、导出、修复、引用链、Live、CiteMap、批量、历史、题录库都必须可回归。
5. **可回退**：每波独立提交；不要一次提交几十个文件；保留 diff。
6. **失败如实记录**：如果被外部服务/网络/资源阻塞，写明“未完成 + 原因 + 下次入口”，不要伪造通过。

## 3. 优化清单（全量）

### A. 覆盖与数据接入（P0）

- A1 中文题录库一键导入向导：支持 CNKI/万方/EndNote/RIS 文件，自动字段映射、去重、来源标记、失败行提示；导入后报告显示“本地库补上了 N 条”。验收：100 条约 2 分钟内完成。
- A2 候选补录 + 人工确认：缺 DOI/卷期页码时给候选，用户点选确认；不自动写入不确定字段。
- A3 题录库仪表盘：来源/年份/期刊分布、重复项、覆盖率、批量标签/合并。
- A4 判错反馈入口：报告里“这条判错了”写入本地反馈队列；不自动训练。

### B. 稳定性与性能（P0）

- B1 长文档/批量异步队列：分析、批量支持度、图表核验后台跑；SSE 进度、断点续跑、单条重试；关页不丢。
- B2 结果缓存与只补失败：按引用/断言缓存；重跑只补未完成项。
- B3 模型不可用降级：统一“未完成核验”，不出现“未检测/未判定”冒充结论；给重试/换模型/继续；恢复后只补缺口。
- B4 服务健康与熔断：判官/视觉服务 health、超时、熔断、预热；本地/云端切换不阻塞页面。

### C. 判定可信（P1）

- C1 图表确定性预检：先规则比对数字/单位/趋势，再交给视觉模型；多面板自动裁切；拿不准显示“证据不足”。
- C2 低置信度复核队列：集中列出低置信/证据不足条目，逐条确认；不混入“支持”。
- C3 多源冲突展示：题名/年份不一致显示“来源冲突”，不强行 Exact。
- C4 状态语义统一：Exact/Minor/Unverified/Unknown/Major 在列表、抽屉、导出里同义；Unknown ≠ 未收录。

### D. 修复与复核闭环（P1）

- D1 可控修复：逐字段接受/拒绝、修改前后 diff、撤销历史不设 30 分钟上限、导出保留修改记录。
- D2 分诊批量操作：批量标已修/忽略/待修，可撤销；筛选后批量处理。
- D3 复检 diff 可视化：状态迁移、字段变化、支持度变化用颜色/箭头展示，点击跳条目。
- D4 导出与批注：导出预设、批量导出、批注 PDF 图例/页码索引、证据包 manifest。

### E. Live 与 CiteMap（P1–P2）

- E1 Live 使用前置：站点支持矩阵、三步引导、结果说人话、内置示例、失败三动作；扩展侧显示当前页是否支持。
- E2 CiteMap 读图任务化：三步引导、固定图例、仅全文筛选、焦点模式、机器候选标识、空态解释、深链接。
- E3 CiteMap 半自动扩展：机器抽取 + 人工确认队列；新增主题必须过“证据可定位”门槛。
- E4 demo 模式：`/live?demo=1`、`/citemap?demo=1`，首次打开即可跑通。

### F. 解析与格式（P2）

- F1 真实版式继续收：双栏、表格、脚注、扫描件；每轮盲测；字段级修复，不整体重跑。
- F2 GB/T 规则补全：学位论文、标准、专利、电子资源；每条给“为什么”和修改示例。
- F3 中文归一增强：繁简、全半角、标点、期刊别名、DOI/arXiv 锚点；保持可解释。

### G. 前端与舒适度（贯穿 P0–P2）

- G1 入口与任务路径：顶部三模式（体检/地图/阅读）、最近任务、面包屑、深链接、刷新不丢状态。
- G2 报告阅读器：左侧小地图、严重度筛选、j/k、页码/条目跳转、页内证据缩放/拖拽/上一条下一条。
- G3 图表与地图交互：统一 hover/图例/缩放；CiteMap 平移缩放、焦点高亮、边动画可关；105 节点不卡。
- G4 微交互：页面过渡、骨架屏、抽屉、toast、命令面板；支持“减少动效”。
- G5 状态与错误：统一 loading/empty/unsupported/error；不露 HTTP 状态码；给下一步动作。
- G6 可访问性与分辨率：深浅主题对比度、焦点环、aria、1280/1440/1920 无横向溢出。

### H. 工程质量（贯穿）

- H1 测试与回归：新增交互补单测/E2E；视觉回归；不破坏现有测试。
- H2 可观测性：统一错误码、健康页、任务日志；失败可定位到模型/网络/输入。
- H3 安全默认值：公网才加 token/限流/上传清理/SSRF；本机默认不暴露。
- H4 许可与依赖：新增依赖先过许可证检查；核心不引入 AGPL。

## 5. 数据与截图保存规则

  - UI 默认 1920 宽，另出 1280/1440（布局项）；深浅主题各一张（视觉项）。
  - 截图必须是真实运行页面，不是设计稿。
- 文档：`docs/optimization/` 下写每项的设计/边界/复现命令；`docs/evidence_index.md` 追加条目（编号、路径、口径）。
