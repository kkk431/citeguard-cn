# 国一冲刺 · 第二轮优化规划（旗舰版）

基线：v1.0.13 · 611 tests · 137/137 checks · 22 篇真实语料 529 条 / clean 1.0 · 盲测第 5、6 轮通过。
上一版规划（页内证据/分诊/相关性）偏“补短板”，不够撑“国一叙事”。这一版把它升级成 **一个新品类的完整故事**：

> 从“引文核验器”升级为 **中文论文引用健康工作台**：体检（五维评分）→ 定位（页内证据）→ 修复（自动改格式 + 换文献）→ 复检（diff 闭环）→ 分享（离线证据包），并由 **开放基准 + 公开榜单** 背书。

原则不变：不伪造、不冒充人审、不做视频、移动端不做；每个数字有 JSON/命令/样本量；每个功能完成即截图归档并登记。

## 1. 五个旗舰能力（这轮真正拿来做记忆点）

### F1 引用健康画像（Citation Health Score）✅
一页报告回答“这篇论文的引用到底健不健康”，而不是只列 7 条问题。

- 五维：**真实性**（存在/撤稿/DOI 指向）、**支持度**（引用句 vs 证据）、**相关性**（是否引错文献）、**覆盖**（正文引用/未被引用/只出现一次）、**规范性**（GB/T 7714）。
- 输出：0–100 工作台评分 + 雷达图 + 每维分子/分母 + “最该先修的 3 条”；权重公开（25/25/20/15/15），标明“规则加权，不是期刊标准”。
- 基线：22 篇真实论文的均值与分布，单篇可对照“高于/低于语料基线”。
- 评测：22 篇逐篇可复现；分数由报告 JSON 直接算出，不手填。
- 演示：一页雷达图 + 三条待修，30 秒讲完。
- 量级：4 天。

### F2 修复与替换（Fix & Replace）
> 进度（1.1.5）：确定性修复已完成（1.1.3）；替换建议已完成（1.1.5）——引用语境检索候选 3 条、GB/T 条目可复制、DOI 可打开。检索评测 438 条查询 / 477 候选池：BGE-M3 Recall@1 0.1986、Recall@3 0.3219、MRR 0.2948（BM25 0.1872/0.2580/0.2428）；绝对召回不高，候选只作线索（`docs/replacement.md`、E60）。

从“告诉你错”到“帮你改”，这是评委最容易记住的闭环。

- 确定性修复：GB/T 类型码、标点、作者分隔、年份位置、DOI 格式——生成 before/after diff，可一键复制“修订后的参考文献表”（DOCX/TXT）。
- 替换建议：对“证据不支持/相关性弱”的引用，用**引用语境**检索候选文献（OpenAlex + 本地库），给 3 条真实候选（题名/期刊/年份/DOI），可复制 GB/T 条目。
- 评测（关键，不靠人审）：用 22 篇真实论文的 **543 条引文语境**做检索任务，候选池为 529 条参考文献 + 干扰项；比较 BM25 / 题名匹配 / BGE-M3，报 Recall@1、Recall@5、MRR；替换建议用同一套排序，报 hit@3。
- 边界：候选是“建议”，不是“正确答案”；不自动改写正文；DOCX 只导出修订后的参考文献表，不动原排版。
- 量级：6 天（含评测）。

### F3 撤稿 / 勘误 / DOI 完整性
引用最致命的不是格式错，是“引了一篇已撤稿的论文”或“DOI 指向另一篇”。

- 数据：OpenAlex `is_retracted`、Crossref `update-to` 关系；DOI 解析后的题名与本条题名比对。
- 规则：撤稿（红）、勘误/更新（琥珀）、DOI 指向不一致（红）、期刊不在 DOAJ 白名单（灰提示，不下结论）。
- 评测：OpenAlex 取 100 条已撤稿 + 100 条对照，报召回/误报；构造 100 条 DOI 互换，报检出率。
- 演示：导入一条撤稿文献，报告顶部直接红条“该文献已撤稿”，比任何格式检查都震撼。
- 状态：✅ 已完成（1.1.4）。实测 100 条已撤稿 100% 召回、100 条对照 0 误报（同源一致性，不是独立真值）；99 条构造 DOI 互换 0 条判 Exact、98 条明确写出“DOI 指向另一篇”（`data/experiments/retraction_eval.json`、`doi_swap_eval.json`）。
- 边界：期刊 DOAJ 白名单只做提示、未接入本次判定；撤稿只查结构化标记，撤稿声明未同步到 OpenAlex 的查不到。
- 量级：4 天（实际 1 天）。

### F4 开放基准 CiteBench-CN v2 + 公开榜单
把“我们很准”变成“大家来测”。

- 从 250 条扩到 **500 条**，新增对抗类别：纯编造、作者换、年份偏移、期刊换、DOI 错、撤稿、 predatory 期刊、题名改写；每类 ≥30 条，全部构造标签（如实写明）。
- 公开榜单页（静态，随 mkdocs 发布）：Qwen3-14B / 14B-4bit / 8B / LoRA-1.7B / DeepSeek / BGE 重排，列 macro-F1、准确率、每类召回、延迟、显存；附复现命令。
- 外部参照：AttributionBench（英文，300 条）与 SciCite 引文意图（英文，300 条，若许可）单独列，标明“非中文、非主口径”。
- 量级：5 天。

### F5 机构/课程聚合视图 ✅
从“一篇”到“一批”，讲清楚谁在用。

- 批量上传 20–50 篇 → 聚合页：平均健康分、五维分布、最常见问题 Top 5、按论文排序；可导出 CSV。
- 进度（1.2.0）：`/aggregate?ids=...` + `/api/aggregate(.csv)`；历史页勾选后一键进入。真实演示 21 篇去重论文 / **509 条引用 / 平均 76.1**（A1 B2 C13 D1 E4），最常见 doi/volume 缺字段、未核验 19 篇；Major 9 条经人工核对是两份双栏 PDF 的解析噪声（DOI 被截断），不是真实造假，已写进 `docs/aggregate.md`，不作为准确率口径。
- 量级：3 天。

## 6. 可以怎么吹 / 不能怎么吹

**可以吹**
- 定义了一个新品类：中文论文“引用健康”工作台，五维评分 + 修复闭环 + 证据可点开。
- 543 条真实引文语境的引用检索评测（不是拍脑袋的 demo）。
- 撤稿/DOI 完整性——高利害、评委一听就懂。
- 500 条公开基准 + 榜单 + 复现命令，开放成果可复用。
- 一批论文的聚合视图，说明“谁在用、怎么用”。

**不能吹**
- 健康分是规则加权，不是期刊/学术标准，不能称“权威评分”。
- 替换建议是候选，不是“正确引用”；引用检索 Recall@5 不到 0.6 就如实写。
- 撤稿覆盖取决于 OpenAlex/Crossref，不能说“全网撤稿都能查”。
- 500 条是构造标签，不是人工标注；50 条人审仍待真人。
- 不做“抄袭判定/降重”，不越界。

## 7. 风险与预案

| 风险 | 预案 |
|---|---|
| BGE 检索效果差 | 同时报 BM25 与题名基线；低就写“仅作线索”，不硬吹 |
| OpenAlex 撤稿字段不全 | 加 Crossref `update-to` 双源；仍不全就写覆盖边界 |
| 替换检索候选池泄漏（同论文参考文献） | 评测时排除“同一篇论文”的候选，单列跨论文池 |
| DOCX 改动破坏排版 | 只导出“修订后的参考文献表”，不改原文 |
| 时间不够 | 先保 F1/F2/F3，F4/F5 可缩水；每个功能独立可交付 |
