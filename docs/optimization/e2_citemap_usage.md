# CiteMap E2 使用层：引导、筛选与单断言焦点

日期：2026-11-26
范围：t33 / E2（使用层），只改 CiteMap 页面模板、JS、CSS 与测试；不改 `web/app.py`，不改动 30 篇/4 主题的真实证据数据或断言定义。

## 1. 为什么改

原 CiteMap 首屏能看主题、论文和断言，但第一次访问的人要自己猜：

- 先选主题，还是先点论文？
- 人工作答的“人工示例”和机器层（全文/原子/论文自述）有什么区别？
- 图例在哪？“未发现证据”是不是“断言为假”？
- 一篇论文的证据分散在多个断言下，如何只跟一条断言走？

E2 把这些问题变成页面上的固定结构：三步引导、常驻图例、仅全文筛选、单断言焦点、机器候选标识、筛选/空态解释。

## 2. 页面改动

### 2.1 三步读图

页面顶部新增“三步读这张地图”：

1. **选主题**：跳到主题切换区；
2. **看断言**：跳到单断言焦点；
3. **打开证据**：跳到论文详情。

三个步骤都是页内锚点，不新增路由。

### 2.2 常驻图例

新增固定图例（桌面端 sticky）：

| 图例 | 含义 | 边界 |
| --- | --- | --- |
| 人工证据 | 人工从摘要逐字摘录、带 stance | `verified=false` 仍表示未读全文 |
| 机器候选 | 自动抽取/自动检索，未人审 | **不是证据**，不能单独支撑断言 |
| 未发现证据 | 机器未在摘要中命中逐字句 | **≠ 断言为假**，也不等于已证伪 |
| 全文证据 | 开放全文中逐句命中 | 仍属机器层，不因“全文”升级为人工金标 |

### 2.3 仅全文证据筛选

工具栏新增“仅全文证据”开关：

- 只保留有全文证据（`fulltext=true` / `verified=true` / `Locator` 以 `Full text` 开头 / `extracted_by` 以 `fulltext:` 开头）的论文与证据；
- 筛选后显示“当前 N/M 篇论文有全文证据；其余论文已隐藏”；若一篇都没有，明确说“覆盖不足，不等于断言为假”；
- **不会**把机器全文候选改标成人工证据；人工卡片在筛选后只会减少，不会增加；
- AI 心理健康 / AI 气候与能源两个新主题没有全文层，筛选后会进入空态，提示取消筛选查看摘要级人工示例。

### 2.4 单断言焦点

详情区新增“单断言焦点”：

- 只列出人工断言（过滤机器层生成的 `*_mNNN` 断言），避免把机器层 claim 混进焦点；
- 点一条断言，详情区按论文聚合显示：
  - 人工证据（逐字引文、定位、方法、样本、置信度）；
  - 机器候选（单独标注“机器全文候选/机器原子候选”，并注明未人审、不是证据）；
  - 未发现证据的抽样格（明确“≠ 断言为假”）；
  - 与断言相关的 gap；
- 再次点击同一断言或点“查看全部断言”退出焦点；
- 点击左侧论文会退出焦点并打开该论文详情。

### 2.5 机器候选标识与空态

- 人工证据卡片：`人工示例` + `仅摘要 · verified=false`；
- 机器卡片：`机器全文候选` / `机器原子候选` / `机器候选 · 论文自述结论`，统一带 `未人审`，并加边界说明“机器候选不是人工证据，不能单独作为断言成立的依据”；
- 未发现证据卡片：`未发现证据 · ≠ 断言为假` + `机器未命中 · 未人审`；
- 筛选导致列表为空时，左侧列表/详情分别显示“这是筛选结果，不是数据缺失，也不表示断言为假”。

## 5. 边界与未做

- 只做使用层，不改变证据判定、断言文本、stance、置信度或数据条数；
- 不新增后端路由，不改 `web/app.py`；
- 不声称所有 40 条人工示例都有全文；新主题仍只有摘要级人工证据；
- 单断言焦点只做前端过滤/聚合，不产生“跨论文 meta 结论”；
- 机器候选即使来自全文，也仍是机器层，不能作为“断言成立”的最终依据；
- 截图是真实页面，不是设计稿；未做移动端截图（本轮验收为 1440/1280）。
