## A1 题录库导入向导

- 现状：文件选择后直接 POST `/api/library/import`，解析失败/重复/缺 DOI 要到导入后才知道；多文件逐个导入，没有汇总。
- 目标：
  - `POST /api/library/import/preview`：只解析、不写库；返回解析条数、可新增、重复、缺 DOI/年份/期刊/页码/摘要、格式识别、前 4 条样例。
  - 前端：选择/拖入文件即预览；显示“可新增 / 重复跳过 / 缺字段”和前几条样例；确认后再导入。
  - 不改变现有导入 API 行为和去重规则；多文件汇总。
- 验收：
  - 单测：预览不写库、重复预览去重、缺 DOI 计数。
  - 真实截图：1280 和 1440 宽度，预览面板可见且不溢出。
  - 真实数据：用 `dist/audit_kit/...` 或 `data/library/cnki_demo.enw` 做一次导入预览。
  - 材料：若截图/说明变化，更新佐证/报告中的“导入”描述（本轮先记录，不重建报告）。
