# 替换建议（候选文献检索）

当一条引用「证据不支持 / 相关性弱」时，除了提示问题，还可以按**引用语境**检索候选文献，给出 3 条可核对的线索。

## 产品入口

报告「审稿条目」→ 点开任一条目 → 抽屉里「找替代文献」。

- 查询句：优先用该条在正文里的第一处引用句；没有引用句时用支持度判定里的 claim；再退回题名。
- 来源：OpenAlex 全文检索（`search=`），排除报告里已有的题名，最多返回 3 条。
- 每条给：题名、期刊/年份/来源、GB/T 7714 条目（可复制）、DOI 链接。
- 接口：`GET /api/report/{job_id}/replacement?index=1[&q=...]`，返回 `{index, query, count, candidates, note}`。

**边界**：候选是检索线索，不代表它一定支持这句话；页面明确提示「打开摘要核对后再替换」。不自动改写正文。

## 检索评测（不靠人审）

数据：22 篇真实论文语料，21 篇可解析出「引用句 → 参考文献」映射；候选池是 477 条去重后的参考文献（其余 20 篇天然构成干扰项），共 **438 条查询**。

| 方法 | Recall@1 | Recall@3 | Recall@5 | MRR |
| --- | --- | --- | --- | --- |
| 题名重叠 | 0.1712 | 0.2329 | 0.2763 | 0.2245 |
| BM25（题名+期刊+年份） | 0.1872 | 0.2580 | 0.2900 | 0.2428 |
| BGE-M3（句向量） | **0.1986** | **0.3219** | **0.3973** | **0.2948** |

证据：`data/experiments/replacement_eval_dataset.json`、`data/experiments/replacement_eval.json`；复现：

```bash
python scripts/build_replacement_eval.py
CITEGUARD_EMBED_ENDPOINT=http://127.0.0.1:8090/v1 python scripts/eval_replacement.py
```

**怎么读**：真值是「作者实际引用的那条文献」，不是「哪条文献支持这句话」。引用句往往很短、不含题名，所以绝对召回不高；这张表只用于在同一数据上比较方法，不能解释成「32% 的替换建议是对的」。产品里把它当线索，而不是答案。
