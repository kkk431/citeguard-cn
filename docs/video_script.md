# 演示视频脚本与字幕（take 3，4 分 57 秒）

成片：`dist/citeguard-demo.mp4`（1920×1080，25 fps，H.264/AAC，旁白 + 硬字幕，18.8 MB）。字幕：`dist/citeguard-demo.srt`。

- 录制：`scripts/record_demo_full3.py`（Playwright 一镜到底，真实操作，无剪辑拼接），原始素材 `out/video/raw4/*.webm`，场景打点 `out/video/timeline4.json`。
- 合成：`scripts/build_video3.py`。旁白为 Windows 中文男声（Huihui，离线 SAPI），无背景音乐。
- 同步方式：**全程统一变速**（`setpts=PTS/1.4243`，不再做中段变速）。旁白起点 = 场景打点 / 1.4243，字幕由同一份 cue 列表生成，因此画面、语音、字幕共用一条时间轴。多篇对比的 121 秒等待是真实推理时间，只随全片统一加速。
