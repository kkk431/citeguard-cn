# 原子断言 × 全文证据核验（通用方法）

这是 CiteMap 从“论文级一句话”转向“断言级逐句证据”的第一步，也是
105 格人工核对后唯一诚实的修正方向。

## 方法

1. **断言先原子化**：8 条复合断言拆成 21 条原子断言
   （`data/evidence_map/claims_atomic.json`，人工尚未逐条确认）。
2. **只使用可获取的全文**：30 篇固定论文中，有 21 篇可通过 OpenAlex OA 链接或 Europe PMC
   fullTextXML 取得全文（PMC 覆盖了部分出版社版本；其余出版社 403/跳转失败）。
   全文只缓存文本，PDF/XML 解析后即删除。
3. **通用句子检索**：中文断言遇到英文全文时，仅用一次模型翻译生成英文
   检索词，随后用词面重合排序候选句；不写教育/医学关键词表，不按领域
   分支代码。
4. **逐句判断**：判官对每条“断言 × 候选句”输出
   `full / partial / none`，并必须逐字引用原文；引用不命中候选句就
   直接丢弃/降级。
5. **不猜**：没有全文、没有候选句、判官失败，都返回 `none/error`，
   不把主题相关句包装成证据。

无需联网的科学判断：中文断言对应英文全文时，翻译只用于**检索**，
判官始终看原文断言和候选英文句；翻译不会成为证据。

## 结果（2026-11-15，Europe PMC 补充后）

- 覆盖：21 条原子断言 × 21 篇全文 = **213 个“断言 × 论文”组合**。
- 判定：**完整支持 5、部分支持 8、无证据 200、错误 0**。
- 完整支持覆盖率 **2.3%**；任何支持（full+partial）覆盖率 **6.1%**。
- 105 格人工结果中，7 个“人工判正确且所在论文有本地全文”的证据格中，
  **3 个被完整支持命中（3/7，42.9%）**；其余 4 个没有被本轮严格核验找到
  （小样本，不是全量准确率）。
- 5 条 `full` 判定中 3 条对应人工正例，另 2 条没有人工标签，仍只能算
  “未人审候选”，不写成正确率。
- 分主题：AI 教育 96 组合（1 full / 5 partial / 90 none）；
  医学影像 117 组合（4 full / 3 partial / 110 none）。

## 怎么读

- **高精度、低覆盖**：能拿到全文且人工判正确的正例被抓住；大量 `none`
  是“该论文没有研究这条断言”的真实结果，不是隐藏失败。
- **不能外推**：8/30 全文、2 个人工正例，样本极小；这不是“通用
  CiteMap 已达到 90%”。
- **与旧路线对比**：旧 v1 在 31 条人工核对证据里精确率 25.8%；
  全文逐句 + 逐字引用把“完整支持”限制到 2 条，且 2/2 命中人工正例。
  代价是覆盖率低。

## 复现

```bash
# 1) 抓取可获取的 OA 全文（会缓存到 data/cache/citemap_fulltext/）
python scripts/fetch_citemap_fulltext.py

# 2) 跑 21 条原子断言逐句核验（需配置判官）
python scripts/eval_citemap_atomic_fulltext.py --workers 4

# 3) 与 105 格人工结果交叉汇总
python scripts/summarize_citemap_atomic_fulltext.py

# 4) 重新生成第 16 张证据图
python scripts/make_fulltext_chart.py
```

输出：

- `data/experiments/citemap_atomic_fulltext.json`（逐组合判定与引用）
- `data/experiments/citemap_atomic_fulltext_summary.json`（汇总与人工正例交叉）
- `docs/evidence/shots/final/charts/16-fulltext-atomic.png`

## 边界（必须一起说）

- 全文覆盖 21/30 篇；其余闭源/被出版社拦截的论文无法自动获取，产品对用户上传 PDF 走同一流程。
- 21 条原子断言是规则拆分的，尚未逐条人工确认；`full` 不等于人工金标。
- 判官是单个模型；没有多模型投票/人工仲裁。
- 引用逐字校验只防“编句子”，不防“句子真实但推断错误”；后者需要更细
  的 NLI/人工核对。
- 方法不是针对教育/医学调参：同一套切句、检索、判定、拒答逻辑用于两个
  主题；领域词表没有进入代码。
