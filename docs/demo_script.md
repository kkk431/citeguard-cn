# 现场演示脚本（5 分钟）

目标：用真实操作让评委看到「发现问题 → 给出证据 → 改完再验」的闭环，而不是菜单巡游。演示机提前启动，窗口最大化，浏览器只留一个标签页。

## 0. 开场 20 秒

> 这是引证卫士，一个中文引文核验工作台。它不替人写引用，而是回答三个问题：这条文献真的存在吗？正文真的支持它吗？格式符合 GB/T 7714-2025 吗？

打开 `http://127.0.0.1:8010`，首页停在「上传论文」区域。

## 1. 主场景：一篇论文的体检（2 分 30 秒）

1. 拖入示例 PDF（`demo/` 里的演示稿；或现场随机论文），点「开始核验」。
2. 进度条滚动时讲：解析 → 逐条多源核验 → 支持度判定 → 格式检查，任务可取消、失败可重跑。
3. 报告出来后先看顶部四张卡：总引文数、Exact/Minor/Unverified/Major、支持度分布、合规均分与风险指数。
4. 点开一条 **Major**：右侧证据抽屉显示「题名/作者/年份/DOI 与检索结果的逐字段差异」和「检索来源」。
   > 这条不是模型猜的：三个公开源都没找到对应文献，按规则判为疑似不存在，并保留原始检索记录。
5. 点开一条 **支持度=矛盾**：展示原文引文句和文献摘要中的相反结论，指出「引用的是这篇，但正文说反了」。
6. 点「导出」：报告、参考文献表、RIS/EndNote 一次性带走；再点「证据包 ZIP」说明评测可复现。

## 2. 本地题录库：中文场景的补位（1 分钟）

1. 切到「题录库」，展示 412 条真实中文题录的覆盖率仪表盘（DOI/摘要/年份构成）。
2. 说明：中文期刊大多不在 OpenAlex/Crossref，在线查不到不等于引文错；导入知网/EndNote 导出后，本地库把可确证率从 49% 提到 99.3%。
3. 回到上传页，用同一篇论文再跑一次，指出 Unverified 数量明显下降。

## 3. 图表核验（40 秒）

1. 打开「图表核验」，上传论文里的结果图（或示例图），输入正文里对它的描述。
2. 结果三档：支持 / 部分支持 / 矛盾；点「定位原页」跳到 PDF 对应页，证明判定基于原图而不是图注文字。

## 4. 收尾 30 秒

> 所有数字都能在 `评测` 页复现：中文核验 0.9684、支持度 0.9597（托管）/0.9744（开源 14B）、真实文献 409 条 0 误判、图表 0.96。
> 代码 Apache-2.0，数据和评测脚本一起开放。我们没做视频，因为更希望评委现场随机抽一篇论文来试。

## 断网/故障兜底

| 故障 | 处理 |
| --- | --- |
| 现场网络不通 | 提前设 `CITEGUARD_OFFLINE=1` 重启；解析、GB/T 规则、本地库比对、报告导出全部可用，页面顶部有「离线模式」横幅；大模型判定显示「未判定」而不是编造 |
| 大模型接口超时 | 报告仍会生成，支持度字段为「未判定」；口头说明「判定服务不可用时，产品选择不猜」 |
| PDF 扫描件解析失败 | 用另一篇文本层 PDF；或展示预先跑好的报告（`dist/demo_reports/`） |
| 现场随机论文太长 | 说明任务在后台线程池运行、可取消；切到已完成的报告继续讲 |
| 投屏分辨率低 | 浏览器缩放 110%，只开报告页；证据抽屉字号已放大 |

## 可能被问到的问题（一句话回答）

- **和 GPT 直接问有什么区别？** 检索、规则、格式是确定性的，模型只做「读证据下判断」，且两段式 + 覆盖审计；纯生成基线 0.5159。
- **数据哪来的？** 自建 250 条核验 / 100 条支持度评测 + 22 篇真实论文 409 条引文；外部 SciFact、ChartCheck 零样本。
- **开源模型真的跑过吗？** 14B bf16 / 4-bit、8B、3B VL 都跑过，同口径数字在评测页；CPU 上 1.7B 也跑过，速度慢所以生产建议 GPU。
- **误判怎么办？** 每条结论带证据和来源；不确定就标 Unverified，不硬判；Major 只在高置信匹配失败时给出。
- **有没有真人测试？** 目前是 LLM 标注审计 + 开发者自测，真人用户测试还没做，不冒充。
